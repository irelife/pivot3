# このフォルダについて

ここに置いた SKILL.md は、コーダ（Claude Code）がこのリポジトリで
作業するときの「やりかたの決まり」です。

★ 大事なこと
  ここに置いたものは、コーダへの**指示**になります。
  よそから持ってきたものを入れるときは、かならず中身を全部読んでから
  入れてください。中身を読まずに入れると、知らないうちに
  コーダの動きが変わります。
  とくに CLAUDE.md（絶対的な制約）を書き換えるもの、
  外のサービスへ中身を送るものは、入れないでください。

## いま入っているもの

### karpathy-guidelines
  出どころ：https://github.com/forrestchang/andrej-karpathy-skills （MIT）
  中身：AI がコードを書くときにやりがちな失敗を減らすための、心がけ。
    ・思い込みで書かない。前提を口に出す。迷ったら聞く
    ・いちばん少ないコードで済ませる。頼まれていないものを足さない
    ・直す範囲を最小にする
    ・「できた」と言う前に、確かめかたを決める
  外へは何も送りません。文章だけのファイルです（67行）。

### handoff
  出どころ：https://github.com/mattpocock/skills （MIT）
  中身：いまの話の続きを、別の作業に引き継ぐための引継ぎ書を作ります。
    引継ぎ書は、この箱の一時フォルダに置きます（リポジトリには入れません）。
    合言葉や個人情報は伏せる決まりが、中に書いてあります。
  外へは何も送りません。文章だけのファイルです（16行）。
